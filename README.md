## Aim:
UI/UX Design for Mobile and Web: Applying Gestalt Principles, UI Patterns, and Usability Guidelines
## Algorithm:
1.Select Ajio as the existing case study.

2.Identify the main user flow: Home → Categories 

3.Create mobile frames in Figma.

4.Design the Home screen with search bar, promotional banner, categories and products.

5.Design the Categories screen with product listings, filters and sorting options.

6.Design the Product Details screen with product image, price, rating, size selection and Add to Bag button.

7.Design the Cart screen with selected products, price details and Place Order button.

8.Apply UI/UX principles such as consistency, proximity, similarity and visual hierarchy.

9.Connect the screens using Figma's Prototype feature.

10.Test the navigation and present the final prototype.
